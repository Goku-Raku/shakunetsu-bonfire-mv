# 分鏡設計

> 為了不在公開 repo 裡收錄官方歌詞，這份分鏡只寫段落與畫面，不引用歌詞原文。

## 規格

- 1920×1080，30fps（Studio 預覽）／ 60fps（成片，`--scale=2` 輸出 4K）
- 全長 3:44.80，155 BPM，第 0 小節強拍在 0.20 秒
- 時間軸在 `bonfire-mv/src/mv/BonfireMV.tsx`，每個鏡頭在 Studio 都有同名的 Sequence

## 視覺命題

**一粒火種，被五個人一路餵大，最後變成整片海灘的營火。**

- 母題是「火」：開頭一粒火星，預副歌化成煙火，副歌點燃營火，結尾五人圍著燒小了的營火放鬆。
- 畫風：粗線條、高對比的漫畫龐克動畫風；上面疊一層 RAS 的 cyber 介面（HUD、頻譜、網格、故障、鎖定準星）。
- 色彩：深夜藍打底；火焰橘黃代表熱度；霓虹粉與青色是 Party lighting 與 cyber 感；每位成員有自己的應援色（LAYER 紅、LOCK 綠、MASKING 金、PAREO 粉、CHU² 青）。
- 服裝：參考歷屆 live 服裝與這首歌對應的夏季活動裝，設計一套 MV 專用的「Bonfire」舞台裝：黑色龐克底、迷你禮帽與星星、火焰紋。

## 歌詞呈現

| 樣式 | 長相 |
| --- | --- |
| 開場 rap | 英文單字一次一個，每字一條斜色帶，對到實際唱字時間 |
| 主歌 | 斜色帶上的漫畫描邊字，放在畫面留白處，一行一行在唱到時砸進來 |
| 大字主體 | 沒有人物的畫面，三行大字，關鍵字特大漸層 |
| 呼應句 | 漫畫爆炸對話框，單字逐一彈出 |
| 預副歌 | 中央逐字由模糊變清楚，最後一句越來越大越抖 |
| 副歌 | 墨線描邊大字，唱到哪裡燒成火焰色；括號和聲先出現在小框裡，主唱等和聲唱完一小節才出現 |
| NO, NO!! | 紅色印章與後半句並列，各自落地震動 |
| Feed in／結尾 | 墨線＋硬陰影＋火焰漸層的大字 |

所有歌詞都不會拖過剪接點：會在剪接點前一拍爆散消失（開場 rap 最後一個字例外，它在換鏡頭之後才唱）。

## 切入（カットイン）規則

- 只在五人合奏畫面出現，放在每段合奏最後兩小節，每次剛好一小節、在強拍進出。
- 兩人一組接力、一左一右，配對取自角色關係：PAREO→CHU²、MASKING→LOCK、CHU²→LAYER、LAYER→MASKING。
- 結尾前兩小節五人依舞台站位（LOCK、MASKING、LAYER、PAREO、CHU²）連發，呼應開頭的成員介紹。
- 人像依臉部位置擺放，從左切入時臉在畫面 30%，從右切入時在 70%。
